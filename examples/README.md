## Первичный паспорт ffprobe

Проверено 2026-10-04 после перезапуска, без полного декодирования/просмотра.

| Параметр | oneflight | with-termination |
|---|---|---|
| Длительность контейнера, с | 284.676028 | 344.485032 |
| Видео | MJPEG, 640×480 | MJPEG, 640×480 |
| Число кадров по заголовку | 8524 | 9852 |
| avg_frame_rate | 1000000/33397 (≈29.943 fps) | 500000/17483 (≈28.599 fps) |
| Формат пикселей / диапазон | yuvj422p / full (pc) | yuvj422p / full (pc) |
| Аудио | PCM s16le, mono, 8000 Hz, 128 kbit/s | PCM s16le, mono, 8000 Hz, 128 kbit/s |
| field_order, SAR/DAR | В выводе не указаны | В выводе не указаны |

FPS из заголовка не доказывает реальную частоту камеры или отсутствие пропусков.
Проверить временные метки, interlace и корректность преобразования full range
перед benchmark; не приводить обе записи молча к 30 fps. Отсутствие field_order
не считать доказательством progressive. Основные сравнения проводить без звука;
сохранение аудио проверять отдельно по требованиям проекта.
