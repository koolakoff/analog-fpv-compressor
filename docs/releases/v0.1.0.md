# v0.1.0 — first Windows x64 CLI preview

Compress analog FPV DVR recordings with a shared Python core and an English CLI.
This is the first prerelease; GUI, multi-file processing and an installer are
future work.

## Download and run

Download `analog-fpv-compressor-0.1.0-windows-x64.zip` from this release and
extract the entire directory. Python and NumPy are included.

FFmpeg is **not** included. If a compatible full build is not already installed,
run `setup-ffmpeg.cmd` once to install Gyan.FFmpeg through WinGet (internet
required). Alternatively put `ffmpeg.exe` and `ffprobe.exe` from a full build
in `tools/`, or provide `--ffmpeg-dir`. Gyan's essentials build lacks SVT-AV1.

In PowerShell, from the extracted directory:

```powershell
.\fpv-compress.exe -i "C:\Videos\flight.avi" -o "C:\Videos\flight-small.mkv"
.\fpv-compress.exe --help
```

Target: Windows 10/11 x64. Output directories must exist. Existing files are
never overwritten. Cancel with Ctrl+C. Use a new output filename on repeat runs.

## Included behavior

- AV1 by default, with optional HEVC, CRF or target bitrate and downscaling.
- Configurable HQDN3D denoising and automatic/manual deinterlacing.
- Conservative automatic removal of sustained white noise; blue-screen cutting
  is disabled to preserve brief useful frames.
- Audio removal by default; optional synchronized FLAC/MKV or AAC/MP4.
- Analysis-only mode, English logs/events, JSON reports and exact interval mapping.
- Complete decode and timestamp validation before publishing each output.

Default settings: AV1 CRF 48/preset 6, medium HQDN3D, original resolution.
Defaults were calibrated on three DVR samples and remain manually adjustable.

## Validation

The development CLI passed 14 full-file runs on the three supplied recordings;
minimal commands and explicit defaults produced identical encoded video packets.
The final automated suite passed 37 tests, including cancellation, synchronization,
field detection, display aspect ratio and portable tool discovery.
The frozen EXE is additionally checked outside the repository with Python and
FFmpeg absent from PATH; actual encoding uses tools copied only into the local
test extraction, never into the published ZIP.

Measurements and limitations:
[CLI validation](https://github.com/koolakoff/analog-fpv-compressor/blob/v0.1.0/docs/research/cli-validation-2026-10-04.md) and
[release verification](https://github.com/koolakoff/analog-fpv-compressor/blob/v0.1.0/docs/research/release-validation-2026-10-04.md).
Real interlaced DVR material is still needed; current field tests use synthetic
inputs. A pathological VFR end with forced deinterlacing can be rejected by
strict timestamp validation. Playback review of transient obstacles remains
part of accepting compression quality.
