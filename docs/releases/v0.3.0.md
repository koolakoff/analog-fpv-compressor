# v0.3.0 — Windows x64 GUI + CLI preview

Download the ZIP and extract the entire directory to a writable location.
Double-click `fpv-compress-gui.exe` for the desktop interface, or use
`fpv-compress.exe` from PowerShell. Python, NumPy and Qt/PySide6 are included.
This release is an archive; an application installer is planned for a later stage.

FFmpeg is **not bundled**. Run `setup-ffmpeg.cmd` to install the full build
through WinGet (internet required), use an existing compatible installation,
or place `ffmpeg.exe` and `ffprobe.exe` in `tools/`.

## Changes

- Classic desktop interface with a file queue, drag and drop, output naming,
  basic/advanced settings, stage progress, cancellation and result opening.
- English, Russian, Ukrainian and Slovak UI; system-language selection with
  English fallback, remembered manual selection and live language switching.
- Shared processing core and job runner for CLI and GUI; independent batches
  and quoted wildcard inputs.
- White noise is removed and flights are split into numbered files by default.
  Choose remove-and-join / `--no-split-flights` or keep noise / `--cut-no-signal off`.
- Audio is removed by default; optional synchronized audio preservation.
- One `fpv-compress.log` beside the executables, overwritten on a new program
  launch. Multiple GUI queues share the session. No per-frame log spam or
  per-output JSON/FFmpeg log files; plans, validation and errors are in the log.
- Application/window icons and user guides with screenshots in four languages.

Application code remains MIT. LGPL Qt libraries are separate DLLs; corresponding
unmodified sources, license texts and upstream attributions are included in
`sources/` and `licenses/`. No Qt Virtual Keyboard, PDF or QML/Quick modules are shipped.

## Validation

79 automated tests passed. Real DVR processing with the new split default
produced two home-recording outputs with all 4,080 useful frames retained and
only media files in the output directory. The extracted release is additionally
checked outside the development environment for CLI encodes, Unicode paths,
GUI translations/icons and two-part default splitting.

Download the `.zip.sha256` file to check the archive checksum. Keep `_internal/`
beside both EXEs. Save a copy of `fpv-compress.log` after an error before relaunching.
