# v0.4.0 — Windows x64 GUI + CLI preview

Extract the entire ZIP to a writable folder and run `fpv-compress-gui.exe`.
Use `fpv-compress.exe` for the command-line interface. Python, NumPy and
Qt/PySide6 are included. This is an archive, not an application installer.

FFmpeg is **not bundled**. Run `setup-ffmpeg.cmd` to install the full Gyan
build through WinGet (internet required), use an existing compatible full
installation, or place `ffmpeg.exe` and `ffprobe.exe` in `tools/`.

## Changes since v0.3.0

- Two progress bars: current stage and overall batch progress, with elapsed
  time and an approximate, updated total-time estimate.
- Compact status showing the input filename, queue position and stage;
  successful completion is highlighted in green.
- Remember the last input folder and white-noise mode. Other processing settings
  retain their defaults on restart. Output folder selection starts from the input
  folder when no valid output folder has been selected.
- Clear encoder labels: **AV1 (SVT-AV1)** and **HEVC / H.265 (x265)**.
- Fix false duration-validation failures for silent video parts with gaps in
  source timestamps, retaining frame-count, timestamp and decode checks.
- Updated user guides in **English, Russian, Ukrainian and Slovak**, included
  in the ZIP with screenshots and illustrations: `README.md` and
  `docs/README_RU.md`, `docs/README_UK.md`, `docs/README_SK.md`.
- Documented Frantisek analysis, controlled denoise comparisons and NVIDIA
  NVENC research. Hardware encoding remains deferred; this release uses CPU
  encoders and retains the existing compression defaults.

## Validation

All 87 automated tests passed, including real FFmpeg processing, GUI workers,
cancellation, split outputs and sparse-timestamp validation.
The release verification script checks the extracted CLI/GUI in an isolated
environment and verifies all four user guides and illustrations against the sources.

## Licenses and diagnostics

Application code is MIT. Bundled Qt libraries remain separate DLLs; licenses,
notices and corresponding upstream source archives are included in `licenses/`
and `sources/`. FFmpeg has its own separate license.

Keep `_internal/` beside both EXEs. The session log `fpv-compress.log` is
replaced on each application launch; copy it before relaunching after an error.
Download the `.zip.sha256` asset to verify the ZIP checksum.
