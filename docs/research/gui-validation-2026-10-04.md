# Проверка GUI — 2026-10-04

Реализован классический интерфейс PySide6/Qt Widgets в исходниках 0.3.0.
Среда: Windows x64, Python 3.13.15, PySide6/Qt/Shiboken 6.11.2,
NumPy 2.2.6, FFmpeg 9.0.2. GUI установлен в локальную `.venv` через extra
`.[gui]`. Опубликованный ZIP 0.1.0 не обновлялся.

## Что проверено

`benchmarks/validate_gui.py` создаёт настоящее окно `MainWindow`, добавляет
исходники, нажимает кнопку запуска и выполняет Qt event loop. Окно скрыто,
но работают реальные виджеты, GUI-worker, QThread, signals/slots, общий
runner, анализ и FFmpeg. Это проверка GUI-пути, а не подмена запуска CLI.

Во время обработки язык переключается с русского на украинский, затем
словацкий. Таймер каждые 100 мс проверяет отзывчивость event loop.
После обработки сохраняются кадры окна средствами Qt. Полные исходники,
результаты, планы, English logs/events и FFmpeg diagnostics остаются локальными.

Материалы: `outputs/gui-validation/summary.json`, `defaults/`, `home-split/`,
`defaults.png`, `home-split.png`; console transcript —
`outputs/gui-validation.console.log`. В summary записаны настройки, события
прогресса, heartbeat и ссылки на отчёты. AVI/медиа/объёмные логи исключены из Git.

## Автоматические проверки и визуальная проверка

Итоговый набор — 72 теста. Qt-проверки охватывают:

- одинаковый набор ключей четырёх каталогов и сохранность template placeholders;
- перевод виджетов, English fallback и сохранение языка в QSettings;
- сохранение выбранных параметров при переключении языка;
- добавление входов без дублей, defaults и взаимоисключающие snow-режимы;
- настоящую обработку с продолжением очереди после ошибочного входа;
- responsive event loop и смену языка при отключённых настройках обработки;
- разделение с дочерними строками, отчётами и открытием правильных путей;
- ошибку следующей части с сохранением готовой и доступом к общему частичному отчёту;
- отмену без публикации результата и без запуска следующего входа;
- закрытие занятого окна с отменой и ожиданием очистки.

Полный лог: `outputs/gui-final-tests.log`; отдельные GUI-проверки:
`outputs/gui-final-widget-tests.log`. Прежние CLI-тесты и проверки ядра сохранены.

При проверке fallback обнаружено, что возвращённая из Python QTranslator
пустая строка показывается как пустой перевод. Теперь отсутствующий ключ
явно возвращает английский source string; это покрыто regression assertion.
Для потоковых Qt-тестов используется настоящий QEventLoop: ожидание через
QTest.qWait на Windows мешало Python-worker получать GIL. Продукт использует
app.exec/event loop и не применяет такое ожидание.

Отрисованы русский, английский, украинский и словацкий интерфейсы, а также
узкое окно с дополнительными настройками. Проверены стандартный Windows-стиль,
системный Segoe UI, диакритика, расположение языка справа, подписи таблицы и
доступность параметров через прокрутку. Qt offscreen-плагин Windows не загрузил
системные шрифты, поэтому финальные снимки получены Windows-плагином из скрытых
виджетов, без захвата пользовательского рабочего стола.
Снимки: `outputs/gui-final-{en,ru,uk,sk}.png`, `outputs/gui-final-sk-small.png`.

Собран Python wheel, проверены четыре JSON-каталога и оба entry points.
Импорт CLI не загружает PySide6. `pip check` прошёл. Этот wheel — Python-пакет,
не новый portable-релиз; упаковка GUI с Qt ещё не выполнена.

Позднее в тот же день GUI включена в ZIP 0.3.0 вместе с CLI. Проверка
изолированной распакованной поставки и исправление зависимости ICU описаны
в [проверке релиза](release-validation-2026-10-04.md). Текущий набор —
79 автоматических тестов, все прошли; лог `outputs/release-0.3.0-tests.log`.

## Повторение

```powershell
.\.venv\Scripts\python.exe -m pip install -e ".[gui]"
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe benchmarks/validate_gui.py --directory outputs/gui-repeat
```

Для интеграционных тестов задать `FPV_FFMPEG_BIN`, если FFmpeg не находится
через PATH. Каталог полного GUI-прогона должен быть новым. Для пользовательской
проверки запустить `.venv\Scripts\fpv-compress-gui.exe` и выбрать свои файлы.
