# План первой версии

Дата: 2026-10-03. Основание: [требования](requirements-v1.md).
Итоговое видение и причины решений: [источник истины](source-of-truth.md).
Ниже — последовательность реализации на основе последних обсуждений;
конкретные интерфейсы и численные настройки пока являются проектными предложениями.

## 1. Подготовить инструменты и описать образцы

- Проверить Python и NumPy для исследовательского прототипа.
- Подготовить FFmpeg/ffprobe со сборкой `libsvtav1`, `libx265`, фильтрами
  `idet`, `bwdif`, `hqdn3d`; сохранить версии и список возможностей.
- Получить ffprobe JSON для двух AVI в `examples/`: потоки, длительность,
  codec, FPS, field order, SAR/DAR, аудио и размеры.
- Просмотреть записи и разметить полезное видео, полный снег и границы переходов.
  Название файла не считать доказательством его содержимого.

Результат: воспроизводимый паспорт образцов и небольшая ручная разметка.
Инструменты уже установлены и проверены; см. `setup.md`. Паспорт и разметка
ещё не подготовлены.

## 2. Сделать минимальный benchmark

Выбрать несколько отрезков примерно по 20–40 с: чистый сигнал, умеренные помехи,
быстрое движение/ветки/трубы, сильные помехи с полезным изображением и полный снег.
Сравнить AV1 без HQDN3D и с HQDN3D при нескольких настройках качества;
добавить ограниченное сравнение с x265 при сопоставимой полезности изображения.
CRF разных кодировщиков не считать одинаковым уровнем качества.
Для SVT начать около preset 6; ограниченно сравнить 4/6/8 по размеру и времени.
В HQDN3D проверить осторожное temporal luma и более сильное chroma.

Собирать размер, битрейт, время, скорость кодирования, версии и команды.
Отдельно визуально оценивать движение, геометрию и кратковременные препятствия.
VMAF/PSNR относительно шумного исходника не использовать как главный критерий.

Результат: компактная таблица измерений и выбор базовых настроек;
дополнительные denoisers пока не добавлять.

## 3. Реализовать и откалибровать NoSignalDetector

Поток уменьшенных grayscale-кадров из FFmpeg → NumPy-метрики → автомат состояний
→ список кандидатов и подтверждённых интервалов. Проверить сочетание временной
разницы, корреляции и крупной структуры; откалибровать длительность и запас.
Сначала выводить отчёт интервалов без кодирования и сверять с ручной разметкой.

Проверки: полный снег в начале/середине/конце, переход обратно в полёт,
быстрый разворот, трава, краткая помеха, повреждённый/пустой вход,
полностью no-signal файл. При отсутствии полезных участков поведение должно
быть явным и не создавать вводящий в заблуждение результат.

Результат: детектор без вырезания полезного видео на размеченных образцах.
Не заявлять универсальность по двум файлам; далее нужны записи других DVR.

## 4. Добавить автоматическую проверку interlace

Выбирать несколько нормальных участков после no-signal анализа,
собирать статистику `idet`, определить TFF/BFF/progressive и уверенность.
Предусмотреть ручной выбор и явный результат при неопределённости.
Проверить progressive и настоящий interlaced материал, сравнить
`send_field` с `send_frame` на движении и кратковременных препятствиях.

Результат: обоснованное решение о deinterlace, записанное в отчёт.

## 5. Собрать CLI и финальный pipeline

Probe → анализ → интервалы и решение interlace → FFmpeg filtergraph →
один финальный encode → проверка результата → отчёт.
Склеивать сохранённые отрезки с корректными временными метками;
при сохранении аудио применять к нему те же интервалы и проверять синхронизацию.
Не смешивать temporal-фильтрацией кадры разных полётов на стыке.

Предлагаемые средства контроля: режим анализа без записи видео, отключение
вырезания и HQDN3D, ручной выбор deinterlace, показ воспроизводимой команды.
Исходники сохранять, существующий результат не перезаписывать молча,
незавершённый output не выдавать за успешный. Ошибки зависимостей объяснять явно.

Результат: запуск на полном AVI и воспроизводимый отчёт с mapping исходных
и выходных интервалов, длительностью, размером, параметрами и временем.

## 6. Проверить первую версию на двух полных записях

- Сопоставить вырезание OFF/ON и HQDN3D OFF/ON; измерить вклад каждого этапа.
- Проверить декодируемость, длительность, FPS, соотношение сторон,
  границы склеек и аудио согласно выбранной политике.
- Просмотреть полезные участки и препятствия рядом с границами вырезания.
- Зафиксировать выбранные параметры, ограничения и инструкцию запуска.

Готовность V1: pipeline воспроизводимо работает на предоставленных образцах,
подтверждённый снег удаляется, полезные участки сохраняются, выигрыш в размере
и цена по времени измерены. Численные цели утвердить после baseline.

Следующий шаг: подготовка паспорта двух AVI и выбор фрагментов для baseline.
