## Особенности pip и песочницы

Старый pip 23.0.1 не принял цепочку HTTPS-сертификатов при загрузке NumPy.
Для успешной установки доверенные сертификаты ROOT/CA из хранилища Windows
экспортированы в локальный `.venv/windows-ca.pem`, затем использовано:

```powershell
.\.venv\Scripts\python.exe -m pip install --cert .venv/windows-ca.pem -r requirements.txt
```

Проверка HTTPS не отключалась, глобальная конфигурация pip не менялась.
Этот файл локален и не включается в Git; на другой машине обычно достаточно
обычной команды из README. При аналогичной ошибке нужен доверенный CA
соответствующей среды, а не отключение проверки сертификатов.

Интерпретатор пользовательского Python и установку пакетов проверяли вне
песочницы: её отдельная учётная запись не имеет доступа к запуску этого Python.
Это ограничение среды Codex, не отсутствие Python у пользователя.
