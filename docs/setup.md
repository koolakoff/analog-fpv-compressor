## Особенности доступа из Codex

В песочнице HTTPS Git выдал Windows Schannel `SEC_E_NO_CREDENTIALS`;
клонирование вне песочницы прошло успешно без изменения TLS или SSH.

Отдельная учётная запись песочницы видит другого владельца репозитория
и может выдавать `detected dubious ownership`. Для чтения использовалось
точечное исключение, без глобальных изменений:

```powershell
git -c safe.directory=D:/work/my_prjects/analog-fpv-compressor status
```

Пользовательский Python из песочницы не запускался из-за ограничения доступа;
его и зависимости проверяли вне песочницы.

## История исправления HTTPS pip

При первой установке на Python 3.10 старый pip 23.0.1 не принял цепочку
сертификатов. Однократно использован экспорт доверенных ROOT/CA Windows
в локальный PEM с `--cert`; проверка HTTPS оставалась включённой.

После перехода на 3.13/pip 26.2.1 обычная установка прошла без `--cert`.
Старый PEM удалён при пересоздании среды. Повторять обход при обычной
подготовке не требуется; глобальная конфигурация pip не менялась.

## Локальная программа

2026-10-04 пакет `analog-fpv-compressor 0.1.0` установлен в `.venv` через
`python -m pip install -e .`. Команда `.venv\Scripts\fpv-compress.exe` доступна,
`pip check` не обнаружил конфликтов. Дополнительные зависимости обработки
не потребовались; FFmpeg и NumPy остались тех же версий. Setuptools используется
как build backend локального пакета. Инструкция запуска хранится в README.

## Сборка Windows-релиза

Установлены PyInstaller 6.22.0 и pyinstaller-hooks-contrib 2026.8 через pip
в локальную `.venv`; версии закреплены в `requirements-build.txt`.
Дополнительные зависимости сборщика установлены pip автоматически.
Сценарии `scripts/build_release.py` и `scripts/verify_release.py` отделяют
сборку от рабочей среды. FFmpeg не включается в публикуемый архив.
